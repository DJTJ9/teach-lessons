📖 Lektion 05 — Keywords-Crashkurs

Ziel: Du kennst jedes relevante Keyword des aktuellen Kartenpools (Origins bis Vendetta) auf Zuruf — inklusive der Akali-relevanten Vendetta-Mechaniken Flow und Empower — und liest in Hamburg keinen Kartentext zweimal.

Ein Konzept: Keywords als Timing- und Combat-Sprache

Riftbound-Keywords zerfallen in drei Gruppen: Timing-Keywords (Action, Reaction, Hidden, Ambush — wann darf ich das spielen?), Combat-Modifikatoren (Assault, Shield, Tank, Deflect — was ändert sich im Showdown?) und Value-Engines (Legion, Vision, Deathknell, XP/Level, Flow — woher kommt Karten-/Board-Vorteil?). Wer die Gruppe erkennt, weiß sofort, worauf er achten muss.

Einordnung: XP/Level ist die Skalierungs-Engine des Spiels — Hunt belohnt genau das, was ohnehin gewinnt (Conquer/Hold), Legends haben seit Unleashed teils XP-Fähigkeiten. Quiz

1. Worin unterscheiden sich Action und Reaction?

Action = nur im eigenen Zug; Reaction = nur im gegnerischen Zug.
❌ Falsch — beide können in beiden Zügen relevant sein. Der Unterschied ist das Chain-Timing.
Action = während Showdowns in jedermanns Zug spielbar; Reaction = zusätzlich im Closed State auf die Chain (Interrupt).
✅ Richtig — Reaction ist das einzige echte Interrupt-Timing. Sobald eine Chain existiert, sind nur noch Reactions legal.

2. Eine Unit mit Assault 2 und 3 Might verteidigt ihr Battlefield. Mit wie viel Might kämpft sie?

5 — Assault gilt immer im Kampf.
❌ Falsch — Assault X gibt +X Might nur als Angreifer. Als Verteidiger wäre Shield X das relevante Keyword.
3 — Assault greift nur als Angreifer.
✅ Richtig — Assault = Angreifer-Bonus, Shield = Verteidiger-Bonus. Beim Angriff hätte sie 5 Might.

3. Du spielst mit Flow eine Karte aus deinem Trash. Wo landet sie danach?

Zurück im Trash — ich kann sie später wieder spielen.
❌ Falsch — Flow-Karten werden nach dem Spielen aus dem Trash ganz aus dem Spiel entfernt. Einmal Recycling, kein Loop.
Ganz aus dem Spiel entfernt.
✅ Richtig — Flow ist Einweg-Graveyard-Value mit eingebautem Exile. Plane jede Flow-Karte als genau einen Extra-Einsatz.

4. Was macht Hunt 2 auf einer Unleashed-Unit?

Wenn die Unit conquert oder holdet, bekommt sie 2 XP (und damit 2 Level Richtung ihrer Level-Boni).
✅ Richtig — Hunt X = „Wenn ich conquere oder holde: X XP", und jede XP = +1 Level. Die Mechanik belohnt genau das punktende Gameplay.
Die Unit macht +2 Schaden gegen erschöpfte Units.
❌ Falsch — das wäre ein erfundener Effekt. Hunt X gibt X XP beim Conquer oder Hold.

Was du gelernt hast

  • Keywords in 3 Gruppen denken: Timing (Action/Reaction/Hidden/Ambush), Combat (Assault/Shield/Tank/Deflect), Value (Legion/Vision/Deathknell/XP-Paket/Flow).
  • Origins-Vokabular: Accelerate (ready ins Spiel gegen Aufpreis), Assault/Shield (Rollen-Boni), Tank (Zuweisungs-Taunt), Deflect (Ziel-Steuer), Deathknell (Deathrattle), Ganking (Battlefield→Battlefield), Hidden (Facedown-Reaction für 0 Energy), Legion, Vision, Temporary (stirbt vor dem Scoring), Mighty (Might ≥ 5).
  • Unleashed: XP/Level (Skalierung), Hunt X (XP für Conquer/Hold), Ambush (Unit mit Reaction-Timing).
  • Vendetta: Flow (aus dem Trash spielen, danach exiled), Empower (aktivierte Fähigkeit mit Kosten).
  • Unverifiziert und vor dem Event zu prüfen: Predict, Backline, Burn — offizielle Quelle: playriftbound.com Rules Hub.
