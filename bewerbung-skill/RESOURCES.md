# Resources

## Knowledge
- [Jinja2 Template Designer Docs](https://jinja.palletsprojects.com/en/stable/templates/) - Syntax für `{% for %}`, Filter, `loop.last`; nachschlagen beim Anpassen von `templates/*.j2`.
- [Jinja2 API: Custom Filters](https://jinja.palletsprojects.com/en/stable/api/#custom-filters) - erklärt, wie `env.filters["tr"]` in `render.py` funktioniert.
- [PyYAML safe_load](https://pyyaml.org/wiki/PyYAMLDocumentation) - YAML-Regeln fürs Frontmatter (Quoting, Listen, Inline-Dicts).
- [Chrome Headless print-to-pdf](https://developer.chrome.com/docs/chromium/headless) - Flags `--headless=new`, `--print-to-pdf`, `--no-pdf-header-footer`.
- [MDN: CSS @page](https://developer.mozilla.org/en-US/docs/Web/CSS/@page) - Seitengröße/Ränder fürs A4-Layout in `cv.css`.
- [MDN: Printing / paged media](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_paged_media) - warum Umbrüche im PDF anders fallen als im Browser.
